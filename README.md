# newnewnew

## Where the notebook lives (super simple version)

1. Open a terminal (the black box where you type commands).
2. Type `ls` and press Enter. You should see a folder named `notebooks`.
3. Type `cd notebooks` and press Enter to “go inside” that folder.
4. Type `ls` again. You will see a file called `player_behavior_analysis.ipynb` — that is the notebook.

## How to open it in Jupyter (click-by-click)

1. While you are still in the project folder, type `jupyter notebook` and press Enter.
2. Your web browser will pop up. Click the `notebooks/` folder.
3. Click the file `player_behavior_analysis.ipynb`.
4. Every gray box is Python code. Click a box to copy or run it.

## If you do not want to run Jupyter

1. Open Visual Studio Code (VS Code).
2. Choose **File → Open Folder…** and pick the project folder.
3. In the Explorer panel, double-click `notebooks`, then `player_behavior_analysis.ipynb`.
4. VS Code will show the same cells; you can copy the code from there.
